# 🏁🏎️La Vuelta Rápida🏎️🏁

## Descripción del Negocio
"La Vuelta Rápida" es una pizzería temática inspirada en el mundo de la Fórmula 1. Nuestro menú está diseñado como una "Grilla de Partida" donde cada pizza, bebida o postre representa algún elemento de este mundo de las carreras.
